# 输入助手底部布局

在手机或宽度不超过 768px 的窗口中，把已有输入助手按钮移到聊天输入框下方；回到宽屏时恢复原位置。

## 安装

1. 在 SillyTavern 中打开「扩展」→「安装扩展」。
2. 粘贴仓库地址：`https://github.com/juxingmaomi/input-helper-bottom`
3. 安装完成后刷新页面。

本扩展不包含输入助手本身，需要先安装并启用酒馆助手和对应的输入助手脚本。

## 适用范围

- 当前版本针对脚本 ID 为 `24ebddd6-7558-4f60-b473-a6a872c14040` 的输入助手。
- 实际匹配的容器 ID：`script_container_24ebddd6-7558-4f60-b473-a6a872c14040`。
- 如果重新创建或导入脚本导致 ID 改变，本扩展不会匹配该脚本，也不会移动其他按钮。
- 宽屏保留原有布局。窄屏按钮居中排列，空间不足时换行。
- 不修改聊天、预设或输入助手脚本内容，不发送网络请求。
- 清单声明最低 SillyTavern 版本为 1.12.13；不同版本、主题和扩展组合仍可能影响布局。

## 更新与停用

在扩展管理中检查并安装更新，完成后刷新页面。停用或卸载后刷新页面可恢复原布局。

## 测试

`tests/browser.cjs` 是离线浏览器场景，配合本地 SillyTavern 测试工具的 `run-browser.cjs` 使用。
覆盖宽窄屏切换、按钮点击、延迟挂载和容器重建。测试使用模拟页面，不等同于完整酒馆集成测试。
